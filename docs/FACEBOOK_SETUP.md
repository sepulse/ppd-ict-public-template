# Facebook dan Telegram

Integrasi sosial adalah pilihan. Jangan letakkan Page access token atau Telegram bot token dalam source code.

Konfigurasi runtime untuk Facebook/Telegram disimpan melalui jadual `settings`/Portal Admin mengikut implementasi sistem. Pastikan hanya pentadbir yang diberi peranan berkaitan boleh mengubah atau menggunakan fungsi publishing.

Sebelum mengaktifkan integrasi production, uji menggunakan aset/halaman ujian organisasi sendiri dan semak format caption, gambar serta audit log.
